### Hi there 👋

我是 Happy，主要做云数据库、云原生数据库和 Serverless 数据库方向的内核与管控系统建设。最近几年关注的重点是：数据库基础设施、Kubernetes 上的数据服务、AI Agent，以及把 AI 接入日常信息处理和内容生产流程。

## 最近在做什么

- **数据库与云原生基础设施**：长期关注 MySQL、TiDB、RocksDB、Redis-compatible KV、数据库备份恢复、Kubernetes Operator 和数据库管控平台。
- **AI Agent 与开发者工具**：尝试把 LLM 接入浏览器插件、代理调试、信息抓取、自动化脚本等日常工程场景。
- **个人知识与内容生产**：探索如何把社交媒体、阅读、收藏和创作流程沉淀成可检索、可总结、可复用的个人信息系统。

## 近期项目

- [chrome-plugin-x-tools](https://github.com/happy-v587/chrome-plugin-x-tools)：给 X/Twitter 做的 Chrome 右侧栏助手。配置自己的大模型接口后，可以对当前内容做翻译、核心观点提取，并生成小红书文案、微信公众号文章和小红书配图。
- [the-second-brain](https://github.com/happy-v587/the-second-brain)：个人第二大脑项目，目标是把公众号、书籍、知乎、小红书、短视频、电商等信息流里的收藏和偏好沉淀为知识中心，再用 AI 做总结、分类和行动建议。
- [http-proxy-dashboard](https://github.com/happy-v587/http-proxy-dashboard)：轻量 HTTP/HTTPS 代理与实时 Web Dashboard，用于捕获、过滤、搜索、统计和导出网络请求，方便本地调试和流量分析。
- [github_trending.py](https://github.com/happy-v587/github_trending.py)：GitHub Trending 抓取工具，支持按语言和时间范围过滤，带缓存、表格输出、JSON / CSV 导出。
- [jepsen-pikiwidb](https://github.com/happy-v587/jepsen-pikiwidb)：围绕 PikiwiDB 做一致性测试的实验项目，用来验证分布式 KV 系统在故障场景下的行为。
- [awesome-database](https://github.com/happy-v587/awesome-database)：数据库资料收集仓库，记录数据库内核、云原生数据库和相关生态的学习材料。
